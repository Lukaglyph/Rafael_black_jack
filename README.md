# ♠️ Casino Blackjack - Raphael vs Ren ♣️

ラファエル（ディーラー）とレン（プレイヤー）の掛け合いが楽しめる、ブラウザで遊べるカジノ風ブラックジャックゲームです。

---

## 🌟 特徴 (Features)

- **オリジナルキャラクターの対戦**
  - ディーラー：ラファエル
  - プレイヤー：レンちゃん
  - ゲーム展開や勝敗に応じてラファエルのセリフが変化します。

- **毎回調整可能なベットシステム**
  - 1ラウンドごとに自由な金額（$10〜$500単位）でベット額を変更できます。

- **CGギャラリー・実績解放システム**
  - レンちゃんの所持金が目標額（$2,000 / $5,000 / $10,000）に達すると、特別グラフィックがアンロックされます。

- **自動保存（localStorage）機能**
  - 所持金、現在のベット額、ギャラリーの解放状態が自動的にブラウザへ保存されます。
  - 途中でページを閉じても、いつでも続きからプレイ可能です（ヘッダーからデータのリセットも可能）。

- **ゲームオーバー & 再挑戦機能**
  - チップが枯渇した際にはゲームオーバー画面が表示され、チップを初期化してリトライできます。

---

## 🎮 遊び方 (How to Play)

1. **`https://lukaglyph.github.io/Rafael_black_jack/`（または `index.html`）をブラウザで開く**
   - 特別なサーバー設定や追加ライブラリのインストールは不要です。標準的なWebブラウザ（Chrome, Firefox, Edge, Safari等）でそのまま動作します。

2. **チップをベットする**
   - `+$10`, `+$50`, `+$100`, `+$500` ボタンを押して希望の掛け金を決定し、「ゲーム開始」を押します。

3. **アクションを選択する**
   - **ヒット（Hit）**: カードを1枚引きます。
   - **スタンド（Stand）**: 現在の手札で勝負します。
   - **ダブルダウン（Double Down）**: 最初の2枚の時、ベット額を倍にしてカードを1枚だけ引きます。

4. **勝敗判定**
   - 手札の合計が21に近い方が勝利（21を超えるとバーストで負け）。
   - ディーラー（ラファエル）は17以上になるまでカードを焼き続けます。
